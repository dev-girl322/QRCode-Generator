# QR Code Generator
A simple QRCode generator application made using HTML, CSS and Javascript from where you can generate and download the QR Code of your favourite sites also you can save and adjust the color, background colors, size and formats of QR codes to generate and download

## Features
- Generate QR Codes for whatever texts you want
- Adjust the color, background color, size and format of the QR Code on your own choice in settings
- Persistent settings across different browser sessions
- Download the generate QR Codes to your system
- Simple and smooth UI with animations
- Loading states for generating and downloading QR codes
